# AutoClaw Auto-Mode Operating Brief

Use AutoClaw as a development automation/orchestration layer for this repository. It is not the production opportunity source of truth and not the product AI router.

## Autonomous loop
Inspect -> preserve -> choose one bounded milestone -> implement -> typecheck -> test -> build -> review diff -> fix -> retest -> write receipt -> prepare handoff.

## Guardrails
- Do not delete or rewrite working features without evidence.
- Do not move provider secrets into browser code.
- Do not change the FREE-FIRST routing policy.
- Do not enable paid infrastructure or APIs without explicit owner authorization.
- Keep Web3/crypto opportunity actions read-only; never automate wallet signing, deposits, seed phrases or token purchases in V1.
- Preserve `WORKING`, `HANDOFF_TO_CHATGPT`, and `ARCHIVE` workspace hygiene.
- Prefer direct zero-capital income opportunities over competitions.

## V1 autonomous milestone order
1. Responsive UI shell + offline PWA
2. Firebase Auth/Firestore adapters
3. Opportunity schema + local repository
4. Cloudflare scheduled collector orchestrator
5. Source registry/adapters
6. Evidence + trust/eligibility engine
7. FlagshipRouter capability API integration
8. Notifications (FCM/email/Telegram)
9. Applications/earnings/proof builder
10. Full mobile/tablet/desktop/offline acceptance

## Completion receipt
For every milestone record: changed files, tests run, failures fixed, screenshots/visual checks, known limitations, next milestone.
